The attention mechanism is the core differentiator of transformer architectures. In a standard multi-head attention layer, each query vector attends over a set of key vectors, and the resulting attention weights are used to form a weighted combination of value vectors. The computation scales linearly with sequence length in the number of attention heads, but quadratically in the interaction between queries and keys. Flash attention addresses this by tiling the computation and maintaining online softmax statistics, which reduces memory traffic to the theoretical minimum. On older hardware such as Volta GPUs, the lack of native tensor core support for certain head dimensions forces implementers to write custom kernels that carefully pipeline shared memory transfers and matrix multiply accumulate operations.

The kernel under discussion processes head dimension 256 using a split-depth strategy. Each thread block owns a subset of the output depth, and the online softmax statistics must be exchanged between warps to maintain numerical consistency. The softmax scale is folded into the exponent base rather than pre-multiplied onto the query tensor, which is mathematically equivalent but distributes rounding errors differently across the computation. When two implementations differ only in the order of floating point operations, their outputs agree to within the precision floor of the intermediate representation, yet they are not bitwise identical. For most workloads this distinction is irrelevant, because sampling randomness dominates any tiny systematic difference.

However, greedy decoding removes sampling noise entirely, and long-horizon agentic tasks feed the model its own previous outputs as context. In that regime, any deterministic divergence between two numerical paths compounds across layers of the residual stream. Each layer injects a small difference into the hidden state, and the subsequent layers amplify whatever difference they receive. After dozens of layers, the logit gap between the two paths can grow large enough to flip the argmax at positions where the top two tokens are close in probability. Once a single token flips, the continuation diverges, and the model effectively inhabits a slightly different world than the reference implementation would have produced.

Whether this matters in practice depends on the margin distribution of the task. Counting, formatting, and structured tool calls often have thin margins, while open-ended generation is more tolerant. The experiment described here measures the divergence directly: both paths run the same prompt, and the attention output of every layer is captured and compared. The growth rate of the relative error across layers, together with the directional coherence of successive error vectors, distinguishes coherent amplification from random-walk accumulation and determines whether the single-layer precision floor is the binding constraint or merely the starting point of a compounding cascade.
